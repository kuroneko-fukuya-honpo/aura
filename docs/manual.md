# AURA の使い方

AURA の使い方を、このページにまとめています。上から読んでも、目次から飛んでも構いません。
くわしい説明は、各節の終わりのリンクから開けます。

## やりたいことから探す

<details>
<summary>ニュースサイトを購読したい</summary>

1. 一覧の右上の「⋮」→ **購読を追加**
2. 「URL・キーワード」の段にサイトの URL（RSS / Atom）を入れて **この URL を購読**
3. 入れるフォルダを選ぶ（選ばなければ「未分類」）

URL が分からないときは、同じ画面の「配信元の一覧」から選べます。→ [購読の追加](/guide/subscribe)

</details>

<details>
<summary>気になる言葉のニュースを集めたい</summary>

「購読を追加」の「Google ニュースのキーワード」に言葉を入れて **このキーワードを購読**。
その言葉の検索結果が、配信元のように一覧に届きます。→ [購読の追加](/guide/subscribe)

</details>

<details>
<summary>あとで読む記事を残したい</summary>

一覧の記事を **長押し** するか、記事の画面の上のしおりを押します。
保存した記事は、整理で消えず、電波のない所でも読めるよう本文と画像を取っておきます。→ [既読と保存](/guide/read)

</details>

<details>
<summary>電車の中や機内で読みたい</summary>

**設定 → 集める →「記事をオフライン用に取っておく」** を「Wi-Fi のときだけ（おすすめ）」か「モバイル通信でも」にしておきます。
新しい記事と保存した記事の本文と画像が、端末に入ります。→ [記事をオフライン用に取っておく](#offline)

</details>

<details>
<summary>文字を大きくしたい・色を変えたい</summary>

記事の画面の右上の「aA」で文字の大きさ、**設定 → 見た目** で明るさとアクセントの色を選べます。→ [テーマと文字](/guide/theme)

</details>

## 基本の使い方

### 購読する

ニュースサイトの RSS / Atom、Google ニュースのキーワード、アプリに入っている配信元の一覧から購読します。
購読はフォルダにまとめられ、一覧の上のタブがそのままフォルダです。
→ [購読の追加](/guide/subscribe)・[フォルダ](/guide/folders)

### 読む

一覧の記事を押すと、記事の画面が開きます。AURA は記事のページから**本文だけを取り出して**、広告やメニューを外して表示します。
左右にめくると、となりの記事へ移ります。
本文を取り出せない記事は、RSS に入っている要約のまま出ます。続きは **元の記事を開く** から。
→ [本文の取り込み](/guide/fulltext)

### 既読と保存

記事を開くと既読になります（一覧をスクロールしただけでは既読になりません）。
右上の ✓✓ で、範囲を選んでまとめて既読にできます。あとで読む記事は保存します。
→ [既読と保存](/guide/read)

### 見え方を変える

一覧の左上の「すべての記事 ▾」で、未読だけ・保存した記事・閲覧履歴などに切り替えます。
**設定 → 見た目** で、リストの見せ方（2 列・大きなカード・リスト）とマガジン（左右にめくる表示）を選べます。
→ [一覧の見せ方](/guide/list-mode)

### いま動いている処理を見る

取り込みや本文の取得などが裏で動いているときは、一覧の右上に **↻ と数** が出ます（1.0.0-359 から）。

- **押す** — いま動いている処理の一覧が 4 秒だけ出ます（触っている間とスクロールしている間は消えません）
- **長押し** — 出したままにします（印がピンに変わります）。もう一度長押しするか ✕ で戻ります

全部終わると「すべて終わりました」と出て、印も消えます。

## 記事をオフライン用に取っておく {#offline}

電波のない所でも記事を読めるよう、**本文と画像を端末に取っておく**設定です（1.0.0-359 から）。
**設定 → 集める →「記事をオフライン用に取っておく」** で、次の 3 つから選びます。

| 選ぶもの | 取っておくもの | 通信 |
| --- | --- | --- |
| **Wi-Fi のときだけ（おすすめ）** | 新しい記事（届いてから 48 時間）と、保存した記事の本文と画像 | Wi-Fi のときだけ |
| **モバイル通信でも** | 同じ | モバイル通信でも取ります。モバイルの通信量を使います |
| **取っておかない** | 取っておきません | 記事を開いたときに、その 1 本だけ取ります |

- 48 時間より古い記事は、開いたときにその 1 本だけ取ります
- 取っておくときは、保存した記事をいちばん先に取ります
- 取っておいた量は、同じ画面の「オフラインで読める記事 N 本」と「使っている量」で分かります。
  整理で消える量は「手元に残す量」で決まります（保存した記事は消えません）

:::note
取っておく処理は、**AURA を閉じているあいだ**に進めます。AURA を開いているあいだは、一覧や記事の表示を先にするため止めて、
閉じてしばらくすると続きから始めます。端末が熱くなっているときも、冷めるまで休みます。
:::

## 快適に使うコツ

- **充電しながら Wi-Fi につないでおく** — 本文の取得や外国語の見出しの翻訳など、重い処理はこのときに進みます。夜のあいだにそろえておくと、朝すぐ読めます
- **読み終えたら閉じる** — AURA を開いているあいだは、裏の重い処理を止めて画面を優先しています。閉じると続きが進みます
- **よく読む記事は保存する** — 保存した記事は本文と画像をいちばん先に取り、整理でも消えません
- **使わなくなった購読は外す** — 購読が少ないほど、更新が早く終わり、通信も電池も少なくて済みます。外すのは **購読の管理** から
- **気になる語は隠す・残す** — 見たくない語の記事を隠したり、いちばん上に出したりできます（フィルタ・[AURA Plus](/plus)）
- **困ったときは** — [お問い合わせ](/contact) からご連絡ください
