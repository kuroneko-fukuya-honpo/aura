# AURA

**同期サーバーを持たない RSS リーダー**です。
**当方はサーバーを運用しておらず、購読リストも既読も受け取りません。** 当方のアカウント登録もありません。

端末間の同期（**[AURA Plus](/plus)**・任意）を使うときだけ Google にサインインします。
そのときも保存先は**利用者ご自身の Google ドライブのアプリ専用フォルダ**（ご自身にも見えない場所）で、
**当方は受け取りません**（[同期のしくみ](/sync)）。同期を使わなければ、購読リストも既読もこの端末の中だけにあります。

作っているのは **黒猫福家本舗** です。

## 何ができるか

購読数に制限はなく、次のことは**無料**で使えます。

- **RSS / Atom の購読** — URL を入れるか、内蔵の配信元一覧から選ぶ
- **フォルダ分け** — 購読をまとめ、タブで切り替える
- **既読の管理** — 未読 / すべて / 保存 の 3 つの見え方
- **オフラインで読む** — 取り込みのあと本文と画像を先に取っておく
- **記事の保存** — あとで読む記事を残す（保持ポリシーで消えない）
- **端末内の検索** — タイトル・要約・本文・媒体名を横断
- **OPML の入出力** — 他のリーダーからの引っ越し、引っ越し先への持ち出し

**[AURA Plus](/plus)** にすると、次が加わります。

- **フィルタ** — 言葉で記事を隠す・上に出す
- **既読の自動整理** — 読み終えた記事を日数で片付ける
- **キーワード購読（無制限）** — Google ニュースの検索結果をフィードとして読む（無料は 3 件まで）
- **[端末間の同期](/sync)** — 購読・既読・保存を複数の端末でそろえる
  （保存先はご自身の Google ドライブ。当方は受け取りません）
- **[Even G2 との連携](/g2)** — スマートグラスに記事を出す
- 広告の非表示、ウィジェットなど（[くわしく](/plus)）

## 当方に送られないもの

- 購読リスト・既読・保存した記事
- 読んだ時間や回数のような記録（そもそも取っていません）

当方はサーバーを運用していないので、これらを受け取ることはありません。

:::note 端末間の同期（AURA Plus・既定はオフ）をオンにした場合
購読・フォルダ・フィルタ・設定・既読・保存した記事の一覧は、
**利用者ご自身の Google ドライブのアプリ専用フォルダ**に保存されます（ご自身にも見えない場所です）。
**当方はこのデータを受け取りません。** 記事の本文と画像は同期しません（各端末が自分で取りに行きます）。
:::

詳しくは [プライバシーポリシー](/privacy) を読んでください。
