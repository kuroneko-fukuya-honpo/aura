# 既読と保存

## 見え方を切り替える

一覧の左上、「AURA」の下の **「すべての記事 ▾」**（いまの見え方の名前）を押すと切り替えられます。

- **すべての記事**
- **未読記事**（はじめはこれ）
- **未読記事（全文取得済）** — オフラインで読める未読だけ
- **すべての記事（全文取得済）**
- **保存した記事**
- **閲覧履歴**

前回の状態は覚えているので、次に開いたときも同じところから始まります。

![見え方の切り替え](/img/guide/read-scope.jpg)

## 既読になるタイミング

- 記事を開いたとき（記事の画面で左右にめくって止まった記事も）
- 設定 →「表示」→ **ブラウザで開く** がオンのときは、一覧でタップしたとき

**一覧をスクロールしただけでは既読になりません。**
先読み（オフラインの取り置き）も既読の状態を一切さわりません。

## まとめて既読にする

右上の ✓✓ から。「既読にする範囲」を選んでから実行します。

- **どこを** — いま見ているところ（フォルダ名や購読名で出ます）／すべてのフォルダ
- **いつより前を** — すべて／1日以上前／1週間以上前／1か月以上前

件数を確かめてから **既読にする**。実行したあと数秒は **取り消す** も出ます。

![既読にする範囲](/img/guide/read-mark-all.jpg)

## 保存

あとで読む記事を残します。**保存した記事は、手元に残す量の整理で消えません**。

- 一覧のセルを**長押し**（もう一度長押しで解除）
- 1 列の表示（リスト・大きなカード）では、セルを**右へ払う**（左へ払うと既読／未読に戻す）
- セルの「⋮」→ **保存する**
- 記事の画面の上のしおりのアイコン

## 古い記事の整理

記事が増えすぎないよう、設定 →「取得」→ **手元に残す量**（容量）に収まるように、配信元ごとに古い記事から自動で整理します。
保存した記事は残ります。

一度消した記事は、配信元にまだ載っていても**取り込み直しません**。
入れ直すと既読が未読に戻ってしまうためです。

:::info AURA Plus — 既読の自動整理
**[AURA Plus](/plus)** では、設定 →「取得」→ **既読の自動整理** で、読み終えてから選んだ日数（3 日・7 日・14 日・30 日）が過ぎた記事を、
更新のときに一覧から消せます（履歴には残ります）。保存した記事は消えません。
:::

:::info AURA Plus — フィルタ
**[AURA Plus](/plus)** では、設定 →「購読」→ **フィルタ** で、特定の言葉を含む記事を隠したり、いちばん上に出したりできます。
:::
