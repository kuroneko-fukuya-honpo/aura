# 既読と保存

## 3 つの見え方

一覧は **未読 / すべて / 保存** を切り替えて見ます。前回の状態は覚えているので、
次に開いたときも同じところから始まります。

## 既読になるタイミング

- 記事を開いたとき
- 一覧をスクロールして、**止まったとき**に通り過ぎた記事
  （設定 → 表示 →「すぐに既読にする」で切れます）

先読み（オフラインの取り置き）は既読の状態を一切さわりません。

## まとめて既読にする

右上の ✓✓ から。確認を挟みます。実行したあとは取り消しも出せます。

## 保存

記事の「保存」か、一覧を右にスワイプ（1 列表示のとき）。
**保存した記事は保持ポリシーで消えません**。

## 古い記事の整理

記事が増えすぎないよう、上限（既定 5000 件）を超えたら古い既読記事から自動で消します。
保存した記事とオフライン指定のものは残ります。

一度消した記事は、配信元にまだ載っていても**取り込み直しません**。
入れ直すと既読が未読に戻ってしまうためです。
