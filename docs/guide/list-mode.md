# 一覧の見せ方

**設定 →「表示」→ リストモード** で 3 つから選びます。

| モード | 見え方 |
| --- | --- |
| 雑誌 | 2 列。ときどき、画像のある記事を全幅で大きく出す |
| 大きなカード | 1 列。画像を大きく |
| リスト | 1 列。文字中心で詰めて表示（はじめの設定） |

1 列の表示（大きなカード・リスト）では、セルを左右に払って保存・既読にできます（[既読と保存](/guide/read)）。

![雑誌](/img/guide/list-magazine.jpg)

## 画像

- **フィード一覧に画像を表示する** — 切ると文字だけの一覧になります
- **Wi-Fi 接続時にのみ画像を表示する** — モバイル回線のあいだは一覧の画像を出しません

購読ごとに画像を出さないようにするには、その購読の設定シートで「記事の画像を表示する」を外します（[フォルダ](/guide/folders)）。

## 記事の開き方

- **ブラウザで開く** — 一覧をタップしたとき、記事画面を挟まずに元記事を開きます
- **アプリ内ブラウザを使用する** — オンなら Custom Tabs（アプリの上に重なるブラウザ）、オフなら端末のブラウザアプリに渡します

どちらも描くのは利用者のブラウザで、AURA がサイトそのものを表示することはありません。

## そのほか

- **スクロールバー** — 一覧の右端にスクロールバーを出します。つまんで動かすと一気に移動でき、動かしているあいだはその位置の記事の年月日が出ます。色・太さ・透明度・形状を選べます
- **本文の埋め込み** — 記事の中の YouTube の動画や X・Instagram・TikTok の投稿を枠で表示します（押したときに初めて読み込みます）
- **隠したときに知らせる** — 隠している部分がある記事の上に「N か所を隠しています」の帯を出します
