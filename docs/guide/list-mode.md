# 一覧の見せ方

**設定 → 表示 → リストモード** で 3 つから選びます。

| モード | 見え方 |
| --- | --- |
| 雑誌 | 2 列。5 件に 1 件、画像のある記事を全幅で大きく出す |
| 大きなカード | 1 列。画像を大きく |
| リスト | 1 列。文字中心で詰めて表示 |

## 画像

- **一覧に画像を出す** — 切ると文字だけの一覧になります
- **Wi-Fi のときだけ画像** — モバイル通信では画像を出しません

## 記事の開き方

- **ブラウザで開く** — 一覧をタップしたら記事画面ではなく元記事を開きます
- **アプリ内ブラウザ** — オンなら Custom Tabs、オフなら端末のブラウザに渡します
