# テーマと文字

**設定 → 表示** から。

## テーマ

- ライト / ダーク / 端末の設定に従う の 3 つ
- 「カスタムカラー」を入れると、クローム（上部の帯）とアクセント（差し色）を選べます
  - 既定は **墨と朱**（クローム = 墨、アクセント = 朱）

## 文字

- **文字サイズ（全体）** — 80〜160%。スライダで動かすと、見本がその場で変わります
- **見出しの文字サイズ** — 一覧の見出しだけ別に決められます
- **Serif** — 見出しに明朝系を使う

記事画面の「aA」からも同じ値を動かせます。
