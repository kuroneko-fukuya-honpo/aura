# テーマと文字

**設定 →「表示」** から。

## テーマ

- **端末に合わせる** / **標準**（明るい・はじめの設定） / **ダーク** / **ブラック**（有機 EL 向けの真っ黒）

## カスタムカラー

**カスタムカラーを使う** をオンにすると、2 つの色を選べます。オフのあいだは既定の **墨と朱** で表示します。

- **プライマリカラー** — 上部のバー・タブ・ドロワーの面。墨・紺・苔・葡萄・鳶・鈍青
- **アクセントカラー** — 選択中の下線・件数・ボタン。朱・藍・緑・紫・琥珀・鉄

アクセントカラーは [更新の進行表示](/guide/progress) の帯の色にも効きます。

![設定の「表示」（テーマとカスタムカラー）](/img/guide/theme-settings.jpg)

## 文字

- **タイトル** — **タイトルに Serif を使用する**（見出しに明朝系を使う）と、**タイトルのフォントサイズ**（12〜22 sp）。一覧の見出しだけの大きさです
- **文字サイズ（全体）** — 80〜160%（5% きざみ）。スライダで動かすと、下の見本がその場で変わります

記事の画面の右上の「aA」からも文字の大きさを動かせます。
