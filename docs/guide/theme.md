# テーマと文字

色は **設定 → 見た目** から、文字は **設定 → 読む・聴く** から変えます。

## テーマ

「画面」の **画面の明るさ** で選びます。

- **端末に合わせる** / **ライト**（はじめの設定） / **ダーク** / **ブラック**（有機 EL 向けの真っ黒）

## カスタムカラー

**カスタムカラーを使う** をオンにすると、2 つの色を選べます。オフのあいだは既定の **墨と朱** で表示します。

- **プライマリカラー** — 上部のバー・タブ・メニューの面。墨・紺・苔・葡萄・鳶・鈍青
- **アクセントカラー** — 選んだ印・件数・ボタン。朱・藍・緑・紫・琥珀・鉄

![設定の「見た目」（テーマとカスタムカラー）](/img/guide/theme-settings.jpg)

## 文字

**設定 → 読む・聴く** の「文字」から。

![設定の「読む・聴く」の「文字」](/img/guide/theme-text.jpg)

- **文字の大きさ（全体）** — 80〜160%（5% きざみ）。スライダで動かすと、下の見本がその場で変わります
- **フォント** — 一覧と記事の見出し・本文の書体。試し読みしながら選べます（明朝体もここで選びます）
- **タイトルの字の大きさ** — 12〜22 sp。一覧の見出しだけの大きさです

記事の画面の右上の「aA」からも文字の大きさを動かせます。
