# 本文の取り込み

RSS には要約しか入っていないことが多いので、AURA は記事のページから**本文だけを取り出して**表示します。
広告・メニュー・関連記事の枠などの飾りを外し、見出し・本文・画像を AURA の文字の大きさと色で読めるようにします。

![本文を取り込んだ記事](/img/guide/fulltext-article.jpg)

## 取り込むタイミング

- **先読み** — 更新のあと、まだ本文を持っていない記事を順に取りにいきます（[オフラインで読む](/guide/offline)）
- **全文を取得** — 記事の画面のいちばん下のボタン。押すとその場で取りにいきます（取り込み済みなら「全文（取得済み）」）

記事の下には **ウェブサイトを表示**（元記事をブラウザで開く）と、**同じ配信元の記事** の一覧も出ます。

![記事の下のボタン](/img/guide/fulltext-buttons.jpg)

## JavaScript で表示されるページ

ページを開いてから JavaScript で本文を描くサイトもあります。そのままでは本文が空に見えるため、
AURA は**本文を取るためだけの見えない画面**でページを描かせてから、本文を取り出します。
サイトごとの決め打ちではないので、この形のサイトなら広く取れます。

- 描かせるときは画像・音・動画・フォントを読み込まず、しばらく待っても描けなければ打ち切ります
- 先読みでこの方法を使うのは 1 回の更新で数本までです。**全文を取得** を押したときは本数を気にせず取りにいきます
- 取り込んだ本文を表示する画面では JavaScript を動かしません（安全のため）

## 複数ページの記事

「続きを読む」でページが分かれている記事は、つなげて 1 本で表示します。
記事の上に「全 N ページの記事をつなげて表示しています」と出ます。途中から取れなかったときは
「N ページ目までを表示しています（続きのページは取得できませんでした）」と出ます。
以前に途中のページまでしか取り込めなかった記事は、記事の下の **全文を取得** を押すと最後のページまでつなぎ直します（Wi-Fi のときは、記事を開いたときにも順に取り直します）。

## 取り込めないとき

配信元によっては本文を取り出せません。取り出した本文が見出しと噛み合わないときも、
関連記事や広告を本文として出さないよう、**わざと使いません**。

そのときは、RSS に入っている本文か要約をそのまま表示します（特別なお知らせは出ません）。
続きを読みたいときは **ウェブサイトを表示** で元記事を開いてください。

一度失敗した記事は、次の先読みで何度も試しません。

## 読みやすくする道具

- 右上の「aA」 — 文字の大きさ（[テーマと文字](/guide/theme)）
- 右上の「⋮」→ **不要な部分を隠す** — 本文に残った余計な部分を選んで隠す。隠したものは「⋮」から表示し直したり戻したりできます
- 画像を長押し →「この画像を今後表示しない」 — この購読で隠す／この記事だけ
- 隠したものの一覧は、設定 →「購読」→ **隠している画像と部分** で確かめて戻せます
- 端末の既定の言語と違う記事には **この記事を翻訳する** が出ます（端末の翻訳を使うので料金はかかりません）
