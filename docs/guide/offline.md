# オフラインで読む

電波のない所でも記事を読めるよう、AURA は**記事の本文と画像を端末に取っておきます**（設定 → オフラインと容量 →「記事をオフライン用に取っておく」）。
次に開くときは通信なしで読めます。一覧では、オフラインで読める記事に雲の印が付きます。

## 取っておく決まり

- 取っておくのは、新しい記事（届いてから 48 時間）と、保存した記事の全文と画像です。保存した記事をいちばん先に取ります
- 取るのは **Wi-Fi のときだけ**です。モバイル回線のあいだは、開いた記事だけ、その 1 本を取ります
- 取る処理は **AURA を閉じているあいだ**に進めます。電池が少ないときと、端末が温かいときは休みます
- 48 時間より古い記事は、開いたときにその 1 本だけ取ります
- 自動で取るのは 1 日 50 MB までです

## 設定

**設定 → オフラインと容量** から。上から次の順に並びます。

- **記事をオフライン用に取っておく** — <strong>Wi-Fi のとき（おすすめ）</strong>か **取っておかない** を選びます。取っておかないときは、記事を開いたときにその 1 本だけ取ります
- **手元に残す量**（容量） — 128MB・256MB・512MB・1024MB・無制限。上限のうち 1/4 を本文、3/4 を画像に使い、超えたぶんは古い順に捨てます（保存した記事は残します）。
  無料のときは 512MB まで、1024MB と無制限は **[AURA Plus](/plus)** の機能です
- **画像の置き場所** — 取り外せる SD カードを挿すと、画像を SD カードに移せます（本文は本体に残ります）
- **画像を小さくして取り込む**（画像） — 長い辺を 1920px までにして、WebP で置きます
- **いま使っている量** — オフラインで読める記事の本数・記事の本文・画像・合計・今月の通信量
- **容量を空ける** — **既読の整理**・**今すぐ整理する**・**取り込んだ全文と画像を消す**（既読の記事ぶん／すべて。保存した記事の全文は残ります）

## 進み具合

取っているあいだは、一覧の右上に **↻ と数** が出ます（[更新の進行表示](/guide/progress)）。
終わると一覧の下に「全文の取り込み 完了」と出ます（**閉じる** で消せます）。
ドロワーの上部にも「電波がなくても読める記事 2187 / 11753」のように、手元にある件数が出ます。

全文が取れない記事の扱いは [本文の取り込み](/guide/fulltext) を読んでください。
