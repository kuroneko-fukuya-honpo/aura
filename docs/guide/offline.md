# オフラインで読む

**設定 →「取得」→「オフラインの深さ」** を決めると、取り込みのあと
新しい記事から順に本文を取っておきます。次に開くときは通信なしで読めます。

- **画像も含める** — 本文と、本文の中の画像まで取ります（既定）
- **本文だけ** — 画像は取りません。モバイル通信を節約したいときに
- **しない** — 先読みせず、記事を開いたときに取りにいきます

何件まで手元に残すかは、**設定 →「取得」→「手元に残す量」**の容量から自動で決まります。
どの回線で取りにいくかは、**設定 →「取得」→「通信」**で
「フィードの更新」「全文の取得」「画像の取得」ごとに別々に決められます。

## 進み具合

先読み中は一覧の下に帯が出ます。終わったら内訳（取れた件数 / 失敗 / 画像）を
12 秒だけ残します。ドロワーの上部にも「オフラインキャッシュ 51 / 192」のように出ます。

## 全文が取れない記事

配信元によっては本文を取り出せません。抽出した本文が見出しと噛み合わないときは、
**わざと保存しません**（関連記事や広告を本文として出さないため）。
その場合は RSS の要約のまま表示します。

一度失敗した記事は、次の先読みで何度も試しません。
