# オフラインで読む

更新で記事を取り込んだあと、AURA はまだ本文を持っていない記事を**先読み**して手元に残します。
次に開くときは通信なしで読めます。一覧では、オフラインで読める記事に雲の印が付きます。

## 先読みの決まり

先読みは**件数で区切らず、未取得の記事を最後まで取ります**。ただし通信量が大きくなるときは確かめます。

| 回線 | 自動の更新（定期） | 自分で更新したとき |
| --- | --- | --- |
| Wi-Fi | 黙って全部取る | **200 件以上なら確認**してから全部取る |
| モバイル回線 | 取らない（次の Wi-Fi か、自分で更新したときに） | **件数にかかわらず確認**してから全部取る |

確認には件数と見込みの通信量が出ます（1 件あたり約 0.1MB）。
**取得する** で始まり、**やめる** を選ぶと、アプリを開いているあいだは聞き直しません。

![先読みの確認](/img/guide/offline-confirm.jpg)

:::note
はじめの設定では、全文の取得は **Wi-Fi のみ**です（下の「通信」）。
そのままモバイル回線で更新すると、全文は取らずに「全文は取得しませんでした（Wi-Fi 接続時に取得します）」と出ます。
モバイル回線でも取りたいときは、全文の取得を「モバイル通信も許可」にしてください。
:::

新しく購読を足したときは、その購読の記事を**先に**取ります（走っている先読みを待ちません）。

## 設定

**設定 →「取得」** から。

- **オフラインの深さ**
  - **画像も含める** — 本文と、本文の中の画像まで取ります（はじめの設定）
  - **本文だけ** — 画像は取りません。モバイル通信を節約したいときに
  - **しない** — 先読みせず、記事を開いたときに取りにいきます
- **手元に残す量** — 容量の上限。上限のうち 1/4 を本文、3/4 を画像に使い、超えたぶんは古い順に捨てます（保存した記事は残します）。
  無料のときは 512MB まで、1024MB と無制限は **[AURA Plus](/plus)** の機能です
- **通信** — 「フィードの更新」「全文の取得」「画像の取得」ごとに、**モバイル通信も許可** か **Wi-Fi のみ** かを決められます
- **いますぐ先読み** →「未取得の記事をいま全部落とす」 — まだ本文を持っていない記事を、まとめて取りにいきます
- **キャッシュを今すぐ削除** — 既読の記事ぶんだけ、またはすべて（保存した記事の本文は残ります）

![設定の「取得」](/img/guide/offline-settings.jpg)

## 進み具合

先読みのあいだは、一覧の上の帯に「先読み」と、いま取っている記事の見出しが出ます（[更新の進行表示](/guide/progress)）。
終わると一覧の下に「オフラインキャッシュ 完了」と内訳（取れた件数・失敗・画像・使った通信量）を 12 秒だけ残します。
ドロワーの上部にも「オフラインキャッシュ 2187 / 11753」のように、手元にある件数が出ます。

## たくさん増えたとき

同期・OPML の読み込み・まとめての購読で未取得の記事が一度に大量に増えたときは、
「未取得の記事がたくさんあります」と聞いてきます。

- **いま全部落とす**
- **あとで少しずつ**
- **落とさない** — 大量の未取得を自動では先読みしません（あとで設定 →「取得」から再開できます）

全文が取れない記事の扱いは [本文の取り込み](/guide/fulltext) を読んでください。
