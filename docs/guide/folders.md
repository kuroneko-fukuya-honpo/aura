# フォルダ

購読はフォルダにまとめられます。画面上部のタブがそのままフォルダです。

## 作る・名前を変える・消す

**購読の管理 → フォルダ** から。

- 名前を入れて「作成」
- 各フォルダの「名前」で改名、「削除」で削除
- フォルダを消しても、**中の購読は消えません**。「未分類」に移ります

## 「未分類」

フォルダを指定せずに追加した購読の行き先です。**名前の変更も削除もできません**。
起動のたびに用意されるので、どこにも属していない購読はここに集まります。

## 購読をフォルダに入れる

**購読の管理** で、各購読の行にあるフォルダ名（チップ）を押すと移せます。
1 つの購読が入れるフォルダは 1 つだけです。

## タブの件数

タブの下に出る数字は、いま選んでいる見え方（未読 / すべて / 保存）での件数です。
「空のコンテンツを非表示」を入れると、記事が無いフォルダはタブから消えます
（いま開いているタブは消えません）。
