# フォルダ

購読はフォルダにまとめられます。一覧の上のタブがそのままフォルダで、左上の「≡」で開くドロワーにも
フォルダごとに購読が並びます（見ているフォルダは開いた状態で出ます）。

![ドロワー](/img/guide/folders-drawer.jpg)

## 作る・名前を変える・消す

**購読の管理**（一覧の「⋮」→「購読リストの管理」）の「⋮」→ **フォルダの管理** から。

- 「新しいフォルダ名」に名前を入れて **作成**
- 各フォルダの **名前** で改名（**決定** で確定）
- **削除** を押すと「中の購読は「未分類」に移ります。もう一度押すと削除します。」と出るので、**削除する** で削除
- 右端の「≡」でフォルダの並び順を変える

フォルダを消しても、**中の購読は消えません**。「未分類」に移ります。

## 「未分類」

フォルダを指定せずに追加した購読の行き先です。**名前の変更も削除もできません**。
ドロワーではいちばん上に固定です。

## 購読をフォルダに入れる・またいで動かす

1 つの購読が入れるフォルダは 1 つだけです。動かし方は 3 つあります。

- **購読の管理** — 行を長押しするとつまめます。**フォルダの見出しを越えて落とすと、そのフォルダへ移ります**
  （右端の「≡」なら長押しは要りません）。移すと「「◯◯」を「△△」に移しました」と出ます
- **ドロワー** — 購読を長押しして、そのまま指を動かすと並べ替えになり、**フォルダの見出しを越えるとそのフォルダへ移ります**
  （閉じているフォルダへも落とせます）
- **設定シート**（下）の「フォルダ」で選ぶ

購読の管理で並べ替えられるのは、上の検索欄が空で、絞り込みをしていないときだけです。

![購読の管理（News で絞り込み）](/img/guide/folders-manage.jpg)

## 長押しで開く設定シート

購読を**長押しして、動かさずに離す**と、その購読の設定シートが開きます。
購読の管理でもドロワーでも同じシートです（購読の管理では行をタップしても開きます）。

- **名前を変更**
- **フォルダ** — 入れるフォルダを選ぶ（「＋ 新しいフォルダ」で作って入れることもできます）
- **記事の画像を表示する** — 外すと一覧のサムネイルと記事の上の画像を出しません（本文中の画像は残ります）
- **先頭へ移動** / **サイトを開く**
- **購読を解除**

![設定シート](/img/guide/folders-sheet.jpg)

フォルダの見出しには長押しのメニューはありません（長押しでつまむと、フォルダの並べ替えになります）。

## タブの件数

タブの下に出る数字は、いま選んでいる見え方（[既読と保存](/guide/read)）での件数です。
設定 →「表示」→ **空のコンテンツを非表示** を入れると、記事のないフィードとフォルダをタブとドロワーから隠します。
