# 購読の追加

購読の入口は **「購読を追加」の 1 画面**にまとまっています。開き方は次のどれでも同じ画面です。

- 一覧の右上の「⋮」→ **購読を追加**
- **購読の管理**（一覧の「⋮」→「購読リストの管理」）の「⋮」→ **購読を追加**
- 記事がまだ 1 件も無いときの画面の **購読を追加**

画面の上に 5 つの段が並びます。

| 段 | できること |
| --- | --- |
| URL・キーワード | RSS / Atom の URL を入れる・Google ニュースのキーワードで購読する |
| 配信元の一覧 | アプリに入っている配信元から選ぶ |
| Google ニュース | Google ニュースの公式の分野別フィード（主要・国内・国際・ビジネス・テクノロジーなど） |
| Yahoo!ニュース | Yahoo!ニュースの公式のトピックス |
| 海外の配信元 | 海外の配信元から選ぶ |

![購読を追加（URL・キーワード）](/img/guide/subscribe-add.jpg)

## RSS / Atom の URL から

「URL・キーワード」の段で、配信元の URL を入れて **この URL を購読**。`http://` で始まる古い配信元も読めます
（つながるなら `https://` を先に試し、通ればその URL に切り替えます）。

「記事の画像を表示する」を外して追加すると、一覧のサムネイルと記事の上の画像を出しません（あとから購読の管理で変えられます）。

## キーワードから

同じ段の「Google ニュースのキーワード」に語を入れて **このキーワードを購読**。その検索結果を配信元として購読します。
語を空白で区切ると、どちらも含む記事だけが入ります。
一覧やドロワーでは、キーワード購読にキーワードの印が付くので、URL 購読と見分けられます。

:::info AURA Plus
キーワード購読は**無料で 3 件まで**お使いいただけます。4 件目からは **[AURA Plus](/plus)** の機能です。
無料のまま 4 件以上あるときは、登録の古い 3 件だけを更新し、残りは消さずに更新を止めます。
:::

## Google ニュース・Yahoo!ニュースの段

各社が公式に出している分野別のフィードを、押すだけで購読できます。
購読済みのものには「購読中」と出ます。

![Google ニュースの段](/img/guide/subscribe-google.jpg)

## 配信元の一覧・海外の配信元

URL を調べたくないときは、「配信元の一覧」「海外の配信元」の段から選びます。
アプリの中に持っている一覧なので、どこにも問い合わせずに選べます。
一覧の **まとめて追加** は **[AURA Plus](/plus)** の機能です。

## 追加したあと

追加できると「◯◯ を追加しました」と出て、入れるフォルダを選ぶ画面になります。
既存のフォルダを押すか、「新しいフォルダに入れる」で名前を入れて **フォルダを作成して入れる**。
選ばずに **このまま閉じる** と「未分類」に入ります。

## 記事の本文で選んだ文字から

記事の本文で語を長押しして選ぶと、メニューに **キーワードに追加** が出ます。

![本文で文字を選んだときのメニュー](/img/guide/subscribe-select.jpg)

押すと、入れるフォルダを選ぶ画面が開きます。キーワードの欄には選んだ文字が入っているので、必要ならその場で直してから、入れるフォルダを押してください。
押したフォルダに、Google ニュースのキーワード購読として追加されます。「新しいフォルダに入れる」で、その場でフォルダを作ることもできます。
**キャンセル** を押したときは何も追加しません。

![追加するフォルダを選ぶ画面](/img/guide/subscribe-select-dialog.jpg)

- 追加すると「『〇〇』を『フォルダ名』に追加しました」と出ます。**元に戻す** を押すと取り消せます
- 選んだ文字の前後の空白・改行と、両端のかぎかっこ（『』「」）は外して入れます
- すでに同じキーワードを購読しているときは、画面を開かずに「『〇〇』は登録済みです」と出ます
- 空白だけのときと、50 文字を超えるときは追加できません

キーワード購読の数の決まり（無料は 3 件まで・**[AURA Plus](/plus)** は無制限）は、上の「キーワードから」と同じです。
無料で 3 件あるときは、フォルダの画面の代わりに AURA Plus の案内が出ます。

## ほかのアプリで選んだ文字から

Chrome などほかのアプリで文字を選んだときのメニュー（⋮ の中）にも **AURAキーワードに追加** が出ます。

![Chrome のメニューの中の「AURAキーワードに追加」](/img/guide/subscribe-other-apps.jpg)

押すと、そのアプリの上に同じフォルダの画面が出ます（AURA の画面は開きません）。
フォルダを選ぶと「『〇〇』を AURA の『フォルダ名』に追加しました」と出て、元のアプリに戻ります。選んだ文字が書き換わることはありません。

メニューに出したくないときは、設定 →「その他」→「キーワード」の **ほかのアプリの文字選択メニューに表示** を切ってください（最初は入っています）。

## ほかのアプリから「共有」で購読する（note・YouTube など）

ブラウザや YouTube アプリで見ているページを、**共有 → AURA** で渡すと「共有から購読」の画面が開き、
そのページの RSS を探します。

- **note** — 記事のページを共有すると、その**著者**の RSS を購読します
- **YouTube** — 動画・チャンネル（`@名前` を含む）・再生リストのページを共有すると、そのチャンネルや再生リストの RSS を購読します
- **そのほかのサイト** — ページの中から RSS を探します。いくつか見つかったときは候補から選びます

「このチャンネルを RSS で読み取りますか？」のように確かめてくるので、**読み取る** を押します。
RSS が見つからなかったときは **URL を入力して追加** から手で入れられます。

![共有から購読（YouTube）](/img/guide/subscribe-share.jpg)

:::note
note や YouTube のページの URL を「URL・キーワード」の段に**手で貼っても、この変換はしません**。
ページを共有で渡すか、RSS の URL（note なら `https://note.com/ユーザー名/rss`）を入れてください。
:::

## OPML で持ち込む・持ち出す

**購読の管理**の「⋮」にある **OPML を読み込む** / **OPML を書き出す** から。

- **読み込む** — 他のリーダーから書き出した `.opml` / `.xml` を取り込む
  （OPML に入っているキーワード購読の取り込みは **[AURA Plus](/plus)** の機能です）
- **書き出す** — いまの購読リストを保存する（保存先は自分で選びます）

購読リストは月に 1 度、端末の中に自動で控えも取ります（6 か月ぶんまで）。

## 取得できない購読を片付ける

取れていない購読があると、一覧の上に「N 件の配信元を更新できませんでした」と出ます（**詳細** で内訳と再試行）。
**購読の管理**では

- 上の絞り込みの **⚠ エラー（N）** — 取れていない購読だけに絞る
- 「⋮」→ **取得エラーの N 件を解除** — 確認のうえ、まとめて購読をやめる
