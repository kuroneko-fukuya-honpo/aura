# 購読の追加

右上の「⋮」から **購読を追加** を開きます。入り口は 2 つあります。

## RSS / Atom の URL から

配信元の URL を入れて「この URL を購読」。`http://` で始まる古い配信元も読めます
（つながるなら `https://` を先に試し、通ればその URL に切り替えます）。

追加できたら、そのままフォルダを選ぶ画面が出ます。選ばなければ「未分類」に入ります。

## キーワードから

「Google ニュースのキーワード」に語を入れると、その検索結果を配信元として購読します。
一覧には `[キーワード]` の札が付くので、URL 購読と見分けられます。

:::info
キーワード購読は**無料で 3 件まで**お使いいただけます。4 件目からと、配信元の一覧からまとめて足すのは **[AURA Plus](/plus)** の機能です。
無料のまま 4 件以上あるときは、登録の古い 3 件だけを更新し、残りは消さずに更新を止めます。
:::

## 配信元の一覧から選ぶ

URL を調べたくないときは、**設定 →「購読」→「購読の管理」**の「⋮」→「配信元の一覧から追加」で内蔵の一覧を開きます。
アプリの中に持っている一覧なので、どこにも問い合わせずに選べます。

## OPML で持ち込む・持ち出す

**設定 →「購読」→「購読の管理」**の「⋮」にある「OPML を読み込む」「OPML を書き出す」から。

- **読み込む** — 他のリーダーから書き出した `.opml` / `.xml` を取り込む
- **書き出す** — いまの購読リストを保存する（保存先は自分で選びます）

購読リストは月に 1 度、端末の中に自動で控えも取ります（6 世代まで）。

## 取得できない購読を片付ける

**購読の管理** に「取得エラー（N）」の節が出たら、そこから

- **エラーだけ表示** — 取れていない購読だけに絞る
- **まとめて解除** — 確認のうえ、まとめて購読をやめる

サービスが終了した配信元は「配信元が見つかりません（サービス終了の可能性）」と出ます。
