# 更新履歴

利用者から見えた変化だけを書いています。版の番号は Android の `versionCode` です。

## 19（2026-09-11）

- **文字化けを直した**。配信元のデータに 1 バイトでも異物が混ざると、日本語がまるごと
  `æ–‡å­—åŒ–` のように化けることがあった。Shift_JIS 配信の取り違えも直した
- 設定 → その他に **「文字化けした記事を直す」** を追加。すでに化けて入っている記事を読み直して戻す
  （押すとまず件数を数え、もう一度押すと直す）

## 18（2026-09-11）

- **消した記事が戻ってくるのを止めた**。保持ポリシーで消した記事が次の取り込みで入り直し、
  読み終えた記事が未読に戻っていた

## 17（2026-09-11）

- **`http://` の配信元を読めるようにした**。OPML で持ち込んだ古い購読が軒並み取得エラーになっていた。
  まず `https://` を試し、対応していない配信元だけ `http://` になる
- 取得エラーの文言を分かりやすくした（「配信元が見つかりません（サービス終了の可能性）」など）
- **取得エラーの購読だけを絞り込み、まとめて解除**できるようにした

## 16（2026-09-11）

- **[Even G2 連携](/g2) を追加**。眼鏡に記事を出せるようになった（設定 → 同期 → Even G2）

## 15

- 開いていない記事が既読になってしまう不具合を直した
- 全文取得の失敗をほぼ解消した（混雑時の待ち直し、通信方式の切り替え）

## 14

- 全文抽出に検証を入れ、広告や関連記事を本文として出さないようにした
- Google ニュースの中継 URL を解いて、キーワード購読でも全文を取れるようにした
- 設定に **Debug** タブを追加

## 13

- スワイプ操作（右で保存 / 左で既読）、検索の絞り込みと履歴、オフラインの印
- 端末のダークモード追従、文字サイズのスライダ、読み進み率のバー
- ホーム画面ウィジェット（未読合計と最新 3 件）、OPML の自動バックアップ
- タブレットで一覧と記事の 2 ペイン表示
- 内蔵の配信元一覧から購読を追加できるようにした

## 12 以前

- リストモード 3 種（雑誌 / 大きなカード / リスト）、カスタムカラー、2 段タブ
- オフラインキャッシュの進捗表示、フォルダの作成と並び替え
- 端末内検索、オンボーディング、OPML の入出力
