# 更新履歴

AURA（Article Update & Reading Assistant）

最終更新日: 2026年9月13日

---

区分は次の4つです。

- **機能追加** — 新しくできるようになったこと
- **改善** — もとからあったものを使いやすくしたこと
- **不具合修正** — 直したこと
- **対応** — OS や外部の決まりに合わせたこと

**お使いのバージョンより上を読めば、更新で何が変わるかが分かります。**
お使いのバージョンは、アプリの 設定 →「その他」→「AURA について」でご確認いただけます
（いまは `バージョン 1.0.0` と表示され、うしろの枝番は出ていません）。

見出しの `33-38` は、**その更新で入ったバージョンの範囲**です。33 から 38 までの変更が、
まとめて1回の更新で届きます。

各行の末尾の `(1.0.0-33)` は、**その変更が入ったバージョン**です。
**その番号以降でお使いいただけます。** 1つの機能が何回かに分けて作られたときは、
**出来上がった時点の番号**を書いています。

いちばん上の **次回配信予定** は、**まだお届けしていない**変更です。

**`1.0.0-32` までは以前の書き方です。** 1つの変更に1つの番号を割り当てていないため、
行末の番号は付けていません。見出しのブロックが、その版までにまとめて入った変更を示します。
1つの変更につき1つ番号を進める書き方は **`1.0.0-33` から**です。

## 1.0.0-20〜32（2026-09-13）

・(機能追加)通信の使い方を、**フィードの更新 / 記事の全文 / 画像**のそれぞれで「モバイルも許可 / Wi-Fi のみ / 取得しない」から選べるようにしました。設定 → 同期 にあります
・(機能追加)設定 →「その他」から、使い方・更新履歴・プライバシーポリシーなど公式サイトの各ページを直接開けるようにしました
・(機能追加)すべて既読にするとき、**範囲を選べる**ようにしました。場所（いま見ているところだけ / すべてのフォルダ）と期間（すべて / 1日以上前 / 1週間以上前 / 1か月以上前）を選ぶたびに対象の件数を数え直してお見せします
・(機能追加)**新着があったときに通知**できるようにしました（設定 → 通知・はじめは切）。アプリのアイコンに未読の数字（バッジ）も付きます。アプリを開くと通知もバッジも消えます
・(機能追加)**ホーム画面のウィジェットを作り直しました**。表示する対象（すべて / フォルダ / 購読）を選べ、大きさを広げたぶんだけ件数が増え、縦にスクロールできます。行を押すとその記事が直接開き、更新ボタンで取り込みを走らせられます。色や不透明度も選べます
・(機能追加)**キャッシュを容量で管理**できるようにしました（設定 → 同期）。いま使っている量（本文 / 画像 / 合計）を表示し、上限を 128MB〜無制限から選べます。読み終えた記事のぶんを自動で削除する設定と、その場で削除する操作も用意しました。**保存した記事のキャッシュはどの経路でも消しません**
・(機能追加)**フォルダの並べ替え**をドラッグでできるようにしました（購読リストの管理 → ⋮ →「フォルダの管理」）。指を離した時点で保存され、一覧のタブの並びもそのまま変わります。「未分類」は常に先頭です
・(機能追加)眼鏡（Even G2）に出す一覧に、**オフラインで読めるかどうかの印**を付けました
・(改善)先読みの進み具合が「16 / 1000」のように実際と合わない分母で出ていたのを、**未取得の実数**に直しました。取るものが無いときは走りません
・(改善)未読で絞り込んでいるとき、**記事を開いて戻っても一覧からすぐ消えない**ようにしました。読み終えた記事はグレーでその場に残り、前後の記事との位置関係が保たれます。絞り込み直すのは、タブや購読の切り替え・更新・アプリの開き直しのときです
・(改善)ヘッダーのアプリ名の下に、名前の由来（Article Update & Reading Assistant）を1行表示するようにしました。頭文字の A U R A がアクセント色になります
・(改善)**新着の帯を「反映のスイッチ」に変えました**。裏で記事が入っても読んでいる一覧は動かず、溜まったぶんが「▲ 新着 N 件」として帯に出ます。押すと一覧に入って先頭へ戻ります。自分で更新したときや先頭にいるときは、帯を出さずにその場で入ります
・(改善)**購読リストの管理を作り直しました**。1件2行の見やすい並びにして、上に検索欄とフォルダの絞り込みを置き、行を押すと URL の確認・フォルダの変更・先頭へ移動・購読の解除ができるシートが出ます。フォルダの管理は別画面に、OPML の読み込み / 書き出しは ⋮ に移しました
・(改善)**本文を公開していない記事（有料記事など）を全文取得の対象から外しました**。取れないページを何度も取りにいかなくなります
・(不具合修正)記事の本文の前後に、ポイント案内・SNS ボタン・見出しの重複・フッタ・関連ニュースの見出し一覧が混ざることがあった問題を修正
・(不具合修正)プル更新の輪（くるくる）が、記事のサムネイルの上に長いあいだ重なり続けていた問題を修正。取り込みが終わった時点で消えるようにしました
・(不具合修正)一覧のサムネイルが記事の写真ではなく**媒体のロゴ**になることがあった問題を修正。あわせて、本文の前後に見出しの重複・SNS ボタン・日付・関連ニュースが付いていた配信元（日テレなど）の本文を、記事だけ取り出せるようにしました
・(不具合修正)**同じ記事を何度も取りにいっていた問題を修正**。混雑やタイムアウトで取れなかった記事を覚えておき、しばらく置いてから取り直すようにしました。更新のたびに同じ記事で時間と通信を使うことがなくなります
