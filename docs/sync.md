# 端末間の同期のしくみ

AURA Plus では、購読や設定を **別の端末と同じに保つ**ことができます。
このページは、「何がそろって、何がそろわないのか」「数字がどう見えるのか」を、
なるべくやさしい言葉で説明します。

:::info かんたんに言うと
記事の一覧・未読・保存の**数は 2 台でそろいます**。ただし、**記事の本文と画像はそろいません**
（各端末が自分で取りに行くため）。同期が済むまでの間は、数が一時的にずれることがあります。
:::

## 1. 何がそろうか

次のものが、端末をまたいで同じに保たれます。

- 購読（登録した配信元）
- フォルダ分けと並び順
- フィルタ・隠すルール
- 保存した記事
- 既読／未読の状態
- 記事の一覧（どの記事があるか）

片方の端末で購読を足したり、記事を既読にしたり、保存したりすると、
同期のあとにもう片方の端末にも反映されます。

## 2. 何がそろわないか（そして、なぜか）

**記事の本文と画像は、そろいません。** これは意図した動きです。

本文と画像は容量が大きいため、端末どうしで送り合うと通信量が増えてしまいます。
そこで AURA は、**各端末が自分で配信元から取りに行く**ようにしています。

このため、**同じ記事でも、本文まで持っている端末と、題名だけを持っている端末があります**。
題名だけの記事を開いたときは、その端末がまだ本文を取っていない状態です。
配信元がその記事をまだ載せていれば、次の取り込みで本文が入ります。

## 3. 数字がどう見えるか

**記事・未読・保存の数は、2 台でそろいます。** これらは同期の対象だからです。

ただし、次のことに気をつけてください。

- **同期が済むまでの間は、一時的にずれます。** 片方で操作した直後や、
  それぞれの端末が新しい記事を取り込んだ直後は、数が違って見えることがあります。
  もう一度同期すれば、そろいます。
- アプリの画面に **「✓ そろっています」** と出ていれば、前回の同期の時点で
  ほかの端末と同じ内容になっています。
- **「● 未同期の変更が N 件」** と出ているときは、まだ送っていない操作
  （既読にした・未読に戻した、など）が N 件あるという意味です。
  次の同期で、ほかの端末にもそろいます。

:::note なぜ「相手の数」をその場で見せないの？
AURA は同期サーバーを持たず、利用者ご自身の Google ドライブのファイルを通じてやり取りします。
そのため、アプリはその場で「相手の端末の今の数」を取りに行きません。
代わりに、<strong>「まだ送っていない変更があるかどうか」</strong>で、そろっているかをお伝えしています。
:::

## 4. 初回は時間がかかります

**初めての同期は、配信元が多いと数分かかることがあります。**
最初にすべての記事の一覧を持ち寄るためです。

- **画面を閉じても、同期は続きます。** 設定画面から離れても止まりません。
- **途中で止まっても、次に開いたときに続きから**同期します。やり直しにはなりません。

2 回目からは、前回からの差分だけを送るので、すぐに終わります。

## 5. データはどこにあるか

同期に使うデータは、<strong>利用者ご自身の Google ドライブの「アプリ専用フォルダ」</strong>に入ります。

- このフォルダは、AURA だけが読み書きするための場所で、**利用者ご自身にも見えません**
  （ドライブのファイル一覧には出ません）。
- **黒猫福家本舗（このアプリの提供元）は、このデータを受け取りません。**
  データは、利用者ご自身の Google ドライブの中にだけあります。
- 同期をやめても（サインアウトしても）、端末の購読・設定はそのまま残ります。

くわしい扱いは [プライバシーポリシー](/privacy) をご覧ください。

## 同期を使うには

端末間の同期は **AURA Plus** の機能です。
アプリの <strong>設定 → その他 →「端末間の同期」</strong>から、Google でサインインすると始められます。

機種変更で購読・設定を新しい端末へ移すだけなら、AURA Plus でなくても、
<strong>設定 → その他 →「機種変更（書き出しと読み込み）」</strong>でファイルにして持っていけます。
