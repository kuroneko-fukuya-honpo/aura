# Even G2 と繋ぐ

AURA の記事を **Even Realities G2**（スマートグラス）に出せます。
渡すのは**同じスマホの中だけ**で、外のサーバーは経由しません。

しくみはこうです。

```
AURA（スマホ）── 127.0.0.1 の HTTP ──▶ Even Realities アプリの中のプラグイン ──▶ G2
```

AURA がスマホの中だけに小さなサーバーを立て、眼鏡用のプラグイン
（**AURA for G2**）がそこから記事を読みます。

:::info
Even G2 との連携は **[AURA Plus](/plus)** の機能です。
:::

## 用意するもの

- AURA（この端末に入っていること）
- Even Realities アプリと、ペアリング済みの G2
- 眼鏡用プラグイン **AURA for G2**

## 手順

### 1. AURA 側を入にする

**設定 →「その他」→「Even G2（眼鏡）」** の「眼鏡に配信する」を**オン**にします。

- **8 文字の合言葉**が出ます（押すとコピーできます）
- 通知の許可を聞かれたら許可してください（配信中に常駐通知を出すため）
- ポートは既定で **8777** です

### 2. プラグインに合言葉を入れる

Even Realities アプリで **AURA for G2** を開き、スマホ側に出る画面に
合言葉とポートを入れて「保存してためす」を押します。

「AURA につながりました」と出れば完了です。合言葉は保存されるので、**入れるのは最初の 1 回だけ**です。

### 3. 眼鏡から開く

G2 のメニューから **AURA for G2** を起動します。

## 眼鏡での操作

| 操作 | 動き |
| --- | --- |
| タップ | 進む（フォルダ → 記事一覧 → 本文） |
| ダブルタップ | 戻る。本文ではメニュー（保存 / 既読 / 一覧に戻る） |
| スワイプ（上下） | 選択の移動・本文のスクロール |

- **フォルダ一覧でダブルタップ**すると、すべて → 未読 → 保存 と切り替わります
- 記事一覧の印：`▶` = 選んでいる行 / `●` = 未読 / `★` = 保存済み
- 眼鏡で開いた記事は **AURA 側でも既読**になります。保存も同じです

## うまくいかないとき

| 眼鏡の表示 | 見るところ |
| --- | --- |
| AURA に接続できません | スマホで AURA を起動し、「眼鏡に配信する」がオンか確認 |
| 合言葉が合いません | AURA 側で合言葉を作り直していないか確認し、入れ直す |

配信中は AURA の常駐通知が出たままになります（眼鏡を使っているあいだ AURA は裏に回るため、
通知を出しておかないと OS に止められます）。うまく続かない端末では、AURA を電池の最適化から
外してください。使い終わったら「眼鏡に配信する」をオフにすれば、通知ごと消えます。

## 合言葉がある理由

端末の中の `127.0.0.1` は、**同じ端末の他のアプリからも届きます**。
記事を勝手に読まれないよう、合言葉が合うものにだけ答える作りにしています。
