# プライバシーポリシー

最終更新: 2026-10-27 / 対象: AURA 1.0.0（Android）・AURA for G2 0.97.0（Even G2 のプラグイン）

AURA（以下「本アプリ」）は、**黒猫福家本舗**（以下「当方」）が提供する RSS リーダーです。
**当方は利用者の個人データを受け取りません。** 当方が運用するサーバーは、音声版の台本を AI で書くための中継サーバー（下記「3.」の「AI の台本」）だけで、氏名・メールアドレス・購読の一覧・読んだ記事の記録は受け取りません。
ただし、**無料版（Free）では記事の一覧・マガジン表示・検索の結果・AURA Brief に広告を表示するため、Google の広告 SDK（Google AdMob）を組み込んでいます**。
広告 SDK は、下記「2. 広告（無料版のみ）」の情報を **Google に**送ります。
また、アプリの改善と不具合の直しのために **Google の Firebase**（Analytics・Crashlytics）を組み込んでいます。設定でオフにすると送りません（「3.」の「利用状況と不具合の報告」）。
**AURA Plus では広告を読み込まず、広告 SDK による通信も行いません。**
以下は、本アプリが実際に何をしているかの説明です。

## 1. 当方が収集する情報

**氏名・メールアドレスなど、あなたを特定する情報は集めません。**

本アプリには利用者登録・ログインの仕組みがありません。当方が運用するのは、音声版の台本を AI で書くための中継サーバーだけです（「3.」の「AI の台本」）。
購読リスト・読んだ記事・既読と保存の状態・設定は、端末の外へ送りません（「4. 端末の中に保存するもの」）。
ただし、設定の「利用状況と不具合の報告を送る」がオンのとき（既定はオン）は、使った機能の種類と回数と、アプリが落ちたときの記録が **Google の Firebase** に送られ、当方は Firebase の画面でその集計と記録を見ます（「3.」の「利用状況と不具合の報告」）。
当方が、氏名・メールアドレス・検索の言葉・購読の一覧を受け取ることはありません。記事の題名・要約・本文は、音声版の台本を AI で書くときだけ中継サーバーを通ります（「3.」の「AI の台本」）。

## 2. 広告（無料版のみ）

無料版では、記事の一覧と検索の結果に 6 件ごとに 1 枠、広告を表示します。マガジン表示では 6 頁ごとに 1 頁を広告の頁にし、AURA Brief の「言葉」の区切りにも 1 枠表示します。広告には「広告」と表示します。広告の間隔は変わることがあります（当方の公式サイトに置いた設定のファイルで変えます）。
記事の本文・読み上げ・フォトフレーム・スクリーンセーバー・AURA Brief のレポートの頁・設定画面・Even G2（眼鏡）の表示・ウィジェットには広告を出しません。起動時や記事を開いたときの全画面広告もありません。

また、無料版では、AURA Brief のレポートのダウンロードの画面で、選んだ人にだけ広告（リワード広告）を表示します。最後まで見ると、そのレポートの PDF を 1 回ダウンロードできます（1 日の回数には上限があります）。この広告は、ボタンを押したときだけ表示します。
広告の配信には **Google AdMob**（Google LLC）を使います。

### 広告 SDK が Google に送る情報

広告を表示するとき、Google Mobile Ads SDK は次の情報を収集し、Google に送ります。

| 情報 | 内容 | 使いみち（Google による） |
| --- | --- | --- |
| 端末の識別子 | **広告 ID**（Android の Advertising ID）、**アプリセット ID** | 広告の配信、広告の効果測定、不正防止 |
| おおよその位置 | 通信の **IP アドレス**から推定される地域。**GPS などの正確な位置情報は使いません**（本アプリは位置情報の権限を持ちません） | 地域に合った広告、不正防止 |
| 広告の操作 | 広告の表示・タップ、アプリの起動などの操作 | 広告の配信と効果測定、不正防止 |
| 診断情報 | 広告 SDK のクラッシュログ、読み込みの速さなどの性能情報 | 広告 SDK の不具合の修正と性能の改善 |
| 端末とアプリの情報 | 端末の機種・OS の版・言語・画面の大きさ、本アプリの名前と版 | 端末に合った広告の表示 |

- **記事の内容・購読リスト・読んだ記事は、広告 SDK に渡しません。** 広告は記事の内容に合わせて選ばれるものではありません
- 通信は暗号化されています
- 情報の扱いは Google のポリシーによります。
  [Google のパートナーのサイトやアプリを使用する際の Google によるデータ使用](https://policies.google.com/technologies/partner-sites?hl=ja)・
  [Google のプライバシーポリシー](https://policies.google.com/privacy?hl=ja) をご覧ください

### 広告の設定と同意

- **広告 ID のリセット・削除**、パーソナライズド広告のオプトアウトは、端末の
  **設定 → Google → 広告**（端末により **設定 → セキュリティとプライバシー → その他のプライバシー設定 → 広告**）から行えます
- **EEA（欧州経済領域）・英国・スイスなど**、法令で同意が必要な地域では、広告を読み込む前に同意の画面を表示します
  （Google の User Messaging Platform）。同意の内容は、本アプリの **設定 → 情報とサポート →「広告の同意を変更する」** から変更できます
- **AURA Plus** にすると広告は表示されず、広告 SDK は広告を読み込みません

## 3. 端末の外への通信

本アプリが通信するのは、**利用者が読むために必要な相手**と、<strong>無料版の広告の配信（Google）</strong>と、**音声版の AI の台本のための当方の中継サーバー**です。

| 通信先 | いつ | 何のため |
| --- | --- | --- |
| 利用者が登録した配信元（RSS / Atom の URL） | 取り込みのとき | 記事一覧の取得 |
| `news.google.com` | キーワード購読があるとき | 検索結果のフィード取得と、記事の実 URL の解決 |
| 記事の掲載サイト | 全文を取っておく設定のとき、記事を開くとき | 本文の取得 |
| 記事に含まれる画像の配信元 | 画像を表示・保存するとき | 画像の取得 |
| 配信元のサイトの `/favicon.ico` | 購読の追加時と更新時 | 一覧に出すアイコンの取得 |
| Google（AdMob・User Messaging Platform） | **無料版で**広告を表示するとき（「2. 広告」） | 広告の取得と表示、同意の確認（「2. 広告」） |
| 当方の公式サイト（`kuroneko-fukuya-honpo.github.io`） | クーポンを使っているとき・無料版でアプリを開いたとき（6 時間に 1 回まで） | クーポンの受付の状態と、広告の位置の設定（どちらも公開しているファイル）の確認。こちらから送る情報はありません |
| Google Play | AURA Plus の購入・購入の復元・起動のとき | 購入の手続きと、購入の状態の確認（下の「AURA Plus の購入」） |
| Google（Google ドライブ） | 端末間の同期がオンのとき | 同期（「5. 端末間の同期」） |
| Google（ML Kit） | 記事の言語を判定するとき | 診断と利用の分析（下の「記事の言語の判定」） |
| Google（Firebase Analytics・Firebase Crashlytics） | アプリを使っている間・アプリが落ちたとき（設定の「利用状況と不具合の報告を送る」がオンのとき。既定はオン） | アプリの改善と不具合の直し。送るのは、使った機能の種類と回数・端末の機種と OS の版・落ちたときの記録です。記事の題名や URL、購読の一覧は送りません。設定 → 情報とサポート →「利用状況と不具合の報告を送る」をオフにすると送りません（下の「利用状況と不具合の報告」） |
| Google Fonts（`fonts.googleapis.com`・`fonts.gstatic.com`） | 設定で読むフォントを選んだとき・フォントを選ぶ画面を開いたとき | フォントのファイルの取得。こちらから送る情報はありません |
| 当方の中継サーバー（Cloudflare Workers・`aura-relay.kuroneko-fukuya.workers.dev`）→ Anthropic（Claude API）。Claude が使えないときだけ Google（Gemini API） | AURA Brief の音声版を作るとき・聴けるレポートで回を新しく作るとき（設定でオフにできます） | 音声版の話題を選び、台本を AI が書くため。送るものは下の「AI の台本」のとおりです |
| VOICEVOX の声のデータの配布元（公式） | 音声版の声（猫使アル・猫使ビィ）のデータを取り込むとき | 声のデータのファイルを取るだけです。こちらから送る情報はありません |
| 読み上げエンジンの提供元（例：Google）※ **AURA ではなく、端末の読み上げエンジンが行う通信** | 端末に声が入っていない言語の記事を、設定で許可したオンライン音声で読み上げるとき | 読み上げる記事の文を声にするため、エンジンが提供元のサーバーに送ります。AURA 自身は送りません（下の「読み上げ」） |

- ファビコンは**配信元のサイトから直接**取得します。外部のファビコン取得サービスは使いません。
- これらの通信では、相手のサーバーに接続元の IP アドレスや User-Agent など、
  通常の HTTP 通信に伴う情報が渡ります。これは当方ではなく**各配信元**（広告は Google）が受け取るものです。
  取り扱いは各配信元のポリシーによります。
- 古い配信元のために、暗号化されていない通信（`http://`）も行えるようにしています。
  ただし **まず `https://` を試し、対応していない配信元の場合だけ** `http://` になります。
- 記事を外部のブラウザや「あとで読む」サービス（Pocket 等）で開くのは、利用者が操作したときだけです。
  以降の通信はそれらのアプリとサイトの間で行われます。

### AURA Plus の購入（Google Play）

AURA Plus は Google Play の定期購入でお申し込みいただきます。**お支払いの情報は Google が扱い、当方は受け取りません。**
本アプリは Google Play から購入の状態を受け取り、AURA Plus かどうかを**端末の中で**判定します（当方のサーバーは使いません）。

### AURA Plus のおためし（不正な使い直しの防止）

AURA Plus のおためし（14 日）は、1 台の端末で 1 回だけお使いいただけます。アプリのデータを消したり入れ直したりしてのおためしの使い直しを防ぐため、
おためしを始めるときと、おためし中に AURA Brief の音声版を作るときに、**端末の印**を当方の中継サーバー（下の「AI の台本」と同じ）に送ります。

- **端末の印**: Android の端末 ID（ANDROID_ID。アプリごとに決まる値です）に本アプリだけの値を足して、元に戻せない形（SHA-256）にした文字の並びです。**端末 ID そのものは送りません**。印から、あなたの氏名・電話番号・広告 ID などは分かりません
- **中継サーバーが残すもの**: 印と、おためしを始めた日時だけです。**400 日**で自動で消えます
- **使う目的**: おためしの使い直しの防止だけです。広告や分析には使いません
- 通信できないときは、おためしを始めずに、通信のある所でもう一度お試しいただくようご案内します

### 記事の言語の判定（Google ML Kit）

記事の言語の判定（翻訳の案内を出すかどうか）に、Google の **ML Kit**（言語の識別）を使います。
判定は**端末の中で**行い、**記事の文を外へ送ることはありません。**
ただし ML Kit は、**特定した言語・端末の情報・アプリの情報・性能の数値・端末の ID** を、
診断と利用の分析のために **Google へ送ります**。これらが第三者に渡されることはありません（Google による）。
詳しくは [ML Kit のデータの開示](https://developers.google.com/ml-kit/android-data-disclosure) をご覧ください。

### 利用状況と不具合の報告（Google Firebase）

アプリの改善と不具合の直しのために、Google の **Firebase Analytics**（アプリの使われ方）と **Firebase Crashlytics**（落ちたときの記録）を使います。

- **送るもの**: 使った機能の種類と回数（例: 読み上げを始めた・レポートを書き出した・AURA Plus を申し込んだ。読み上げた記事の言語やレポートの形式などの種類だけ）、いまのプラン（Free / Plus）、端末の機種と OS の版、アプリの版、落ちたときの記録（どこで落ちたか）。Firebase はこのほかに、アプリのインスタンス ID（アプリを入れ直すと変わる ID）と、通信の IP アドレスから推定されるおおよその地域を扱います
- **送らないもの**: 記事の題名・URL・本文、検索の言葉、購読の一覧、クーポンのコード。**広告 ID（Advertising ID）と Android ID は Firebase に集めさせていません**
- **止め方**: 設定 → 情報とサポート →「利用状況と不具合の報告を送る」をオフにすると、Analytics も Crashlytics も送りません。オフのあいだに落ちた記録は、端末に溜めずに捨てます
- 送った情報は Google が扱い、第三者に販売されることはありません。詳しくは [Firebase のプライバシーとセキュリティ](https://firebase.google.com/support/privacy) をご覧ください

### 読み上げ（端末の読み上げエンジン）

読み上げ：AURA は、端末に設定された読み上げエンジン（例：Google 音声認識と音声合成サービス、Samsung のテキスト読み上げエンジン）を使って記事を読み上げます。端末にその言語の声が入っていないときは、設定で許可した場合に限り、エンジンのオンライン音声で読み上げます。このとき、読み上げる記事の文がエンジンの提供元（Google など）のサーバーに送られ、その扱いは提供元のプライバシーポリシーに従います。AURA 自身は、読み上げる文を当方やほかの会社のサーバーに送りません。設定 → 読み上げ →「オンラインの音声合成を使う」で、いつでも止められます。

### AI の台本（AURA Brief の音声版・ベータ）

AURA Brief の音声版「アルとビィのニュース」は**ベータ版**です。予告なく内容を変えたり終了したりすることがあります。
AURA Brief の「聴けるレポート」（レポートに「アルとビィの声も付ける」・AURA Plus）で、その期間の音声版の回がまだ無いときは、ここに書いたのと同じ方法で回を新しく作ります。送るものも同じです（回がすでにあれば、何も送らずにその回を使います）。
台本を AI が書くために、**Anthropic の Claude API** を、当方の中継サーバー（Cloudflare Workers・`aura-relay.kuroneko-fukuya.workers.dev`）を通して使います。
Claude が使えないとき（混み合い・時間切れ・障害など）と、1 日に Claude を使う回数の上限を超えたときだけ、予備として **Google の Gemini API** を使います。送るものはどちらも同じです。

- **話題を選ぶために送るもの**: 音声版の対象（フォルダ・キーワード）の**記事の一覧**（新しい順に 120 本まで）の、**題名・媒体名・日付・1 行の要約**。記事の本文・画像・URL は送りません
- **音声版のために記事の全文を取ること**: AI が選んだ話題の記事（話題ごとに違う媒体から 3 本まで・通常は 9 本まで、じっくり版は 15 本まで）の**全文**を、端末に無ければその場で記事の掲載サイトから取り込みます。その**本文**（1 本 2,000 字まで）と題名・媒体名・日付・URL を中継サーバーに送ります。選ばれていない記事の本文は送りません
- **聞き手の情報**: **よく読む媒体の名前（上位 3 つ）・今月読んだ本数・保存した記事の数**（数と名前だけ）。番組の中の「あなたへの一言」に使います。読んだ記事そのもの・保存した記事そのもの・購読の一覧は送りません
- **そのほかに送るもの**: 音声版の対象の名前（フォルダ名か、キーワード 1 つ）、進行役の名前、端末の言語、台本の言葉のやさしさ（やさしく・もっとやさしく）、**前回の放送の引き継ぎ**（AI が前回作った 150 字ほどのメモ）、**感想の傾向**（「詳しいのが好き」「短めが好き」「よかった話題」など。個々の感想は送りません）。回数を数えるための**端末ごとの識別子**（アプリが初めて使うときに作るランダムな値で、あなたを特定する情報を含みません）と、プラン（Free / Plus）、アプリの版の番号
- **送らないもの**: 購読の一覧そのもの（配信元の URL）、読んだ記事の記録そのもの、検索の言葉、氏名・メールアドレス・広告 ID などの個人の情報。配信元が AI での利用を断っている記事（例: 情報の灯台）は、一覧にも本文にも入れません
- **ウェブ検索で調べること**: 選ばれた話題を詳しく解説するため、Claude が **ウェブ検索**（Claude API のウェブ検索の機能）で、その出来事を調べます（予備の Gemini のときは Gemini API の「Google 検索によるグラウンディング」）。検索に使われるのは記事の内容から作られた言葉で、あなたの情報は含みません
- **取材メモを 24 時間だけ中継サーバーに置くこと**: AI が記事と検索から作った**取材メモ**を、同じ記事の組み合わせで調べ直さないように、**24 時間だけ**中継サーバー（Cloudflare の保存領域）に置き、時間が来たら自動で消します。置き場の名前は記事の URL の組み合わせから作った値で、URL そのものや、あなたの情報は残しません
- **中継サーバーが残すもの**: 上の取材メモと、端末ごとの識別子・その日に作った回数と段ごとの回数（2 日で自動で消えます）、1 回の音声版を作るあいだだけ使う番号（「1 話の券」・1 時間で自動で消えます）。送られた本文や台本の文は残しません（ログに残すのは時刻・結果・回数・使った量だけです）
- **送った内容が AI の学習に使われることはありません**: Claude API（Anthropic の商用の規約）では、送った内容が **Anthropic の AI の学習に使われることはありません**（不正利用の監視のため、Anthropic が一定の期間保存することがあります）。詳しくは [Anthropic の商用利用規約](https://www.anthropic.com/legal/commercial-terms) と [プライバシーポリシー](https://www.anthropic.com/legal/privacy) をご覧ください。予備の Gemini API は有料の枠で処理し、Google の規約により、送った内容が **Google の製品の改善に使われることはありません**（[Gemini API の追加利用規約](https://ai.google.dev/gemini-api/terms)）。当方も、送られた内容を AI の学習に使わせず、製品の改善にも使いません
- **利用者ご自身の API 鍵**: 今の版には、利用者ご自身の AI の API 鍵を使う機能はありません。今後入れる場合も、鍵は**端末の中だけ**に置き、中継サーバーには送りません
- **不正な利用を防ぐため**、Google の **Firebase App Check**（Play Integrity）で、正規の AURA からの要求かを確かめます。このとき、端末とアプリが正しいかの判定が Google を通して行われます
- **回数と広告**: 無料のプランは、広告（リワード広告）を 1 本見ると 1 日 1 話。AURA Plus は 1 日 3 話まで広告なし（4 話目からは広告 1 本・1 日 8 話まで）。じっくり版（話題 5 つ）は広告 2 本です（広告については「2. 広告」）。同じ対象の回は 1 日 1 回作り、同じ日の 2 回目からは端末に残した回を再生します
- **止め方**: 設定 → 読む・聴く → 読み上げ →「AI で台本を書く」をオフにすると、中継サーバーを呼ばず、端末で作った台本で読みます

### ラジオ番組（同じ端末の中のアプリ「らじぽけ」）

記事の中のラジオ番組を確かめるため、また、その番組を再生するために、AURA は同じ端末の中のアプリ「らじぽけ」に、**放送局・番組名・放送の日時**を渡すことがあります。渡すのは**同じ端末の中だけ**で、AURA がこの目的で外部のサーバーに送ることはありません。らじぽけが受け取ったあとの扱いは、[らじぽけのプライバシーポリシー](https://radipocket.github.io/docs/privacy-policy.html)によります。らじぽけが入っていないときは、何も渡しません。

## 4. 端末の中に保存するもの

次のデータは、**すべて端末内のアプリ領域**に保存されます。当方へ送信されることはありません。

- 購読リスト、フォルダ、記事（タイトル・要約・本文）、既読と保存の状態（アプリ内のデータベース）
- 記事の画像のキャッシュ
- アプリの設定（テーマ、文字サイズ、更新間隔、Even G2 連携の合言葉など）
- 購読リストの自動バックアップ（月 1 回・6 世代まで）。保存先は
  アプリ専用の外部ディレクトリ（`Android/data/ca.kuroneko.aura/files/Documents/`）で、
  アプリを削除すると一緒に消えます
- アプリ内の動作ログ。**端末のメモリ上に直近 500 件だけ**保持し、アプリを終了すると消えます
- **不具合の報告用のログ**（設定 →「詳しい設定」→「不具合の報告用のログ」）。
  **利用者がオンにしたときだけ**端末内のファイルに保存します（**オフのあいだは作られません**。はじめはオフです）。
  溜める量は最大 1MB で、超えたぶんは古いものから消えます。**当方へ自動で送られることはありません。**
  外へ出るのは、利用者が「ファイルに書き出す」「共有する」を押したときだけです。
  このログには、購読している配信元の URL と記事の見出しが含まれます（記事の本文・購入の情報は含まれません）
- 無料版では、広告 SDK と同意の画面が、同意の状態や広告の表示に要る情報を端末内に保存します
- **AURA Brief の音声版の作った回**: 台本・取材メモ・調べた出典・元になった記事（題名・媒体名・URL）・音声・この回のレポート（PDF）を、対象ごとに 7 回まで、アプリの中の置き場に残します（2 回目からすぐ再生するため）。当方へは送りません
- **番組レポートの書き出し**: 台本の画面で「この回のレポートを保存（PDF）」を押したとき、選んだ保存先に PDF（台本・取材メモ・元になった記事の一覧）を書き出します。AURA Plus で「音声を保存」を押したときは、端末の「ダウンロード」にも音声を保存します（ご自身で聴くためのもので、配布はできません）
- **VOICEVOX の声のデータ**（猫使アル・猫使ビィ）: 公式の配布元からダウンロードして端末に置きます（約 84 MB）。声は端末の中で作り、読む文を外へ送りません
- **音声版の記録**: 音声版を作ったときの段ごとの結果（日時・対象の名前・段・結果・秒・中継の応答の番号）を、端末の中に新しい 20 件だけ残します（うまく作れなかった理由を確かめるため）。記事の本文や題名は含みません。当方へは送りません
- **音声版の感想**: 台本の画面の感想（よかった・いまいち・もっと詳しく・もっと短く）を、端末の中に 200 件まで残します。中継サーバーに送るのは傾向だけです（「3.」の「AI の台本」）

アプリをアンインストールすると、これらは端末から削除されます。

:::info Android の自動バックアップについて
本アプリは Android の自動バックアップを有効にしています。端末の設定でバックアップが有効な場合、
購読リストや設定などのアプリデータが、**利用者自身の Google アカウント**のバックアップに含まれることがあります。
これは Android の機能であり、当方がその内容を参照することはできません。
:::

## 5. 端末間の同期（AURA Plus）

**AURA Plus** では、購読・設定・既読・保存・記事の一覧を、**別の端末と同じに保つ**ことができます。

- 同期に使うデータは、<strong>利用者ご自身の Google ドライブの「アプリ専用フォルダ」</strong>に保存されます。
  このフォルダは AURA だけが読み書きするための場所で、**利用者ご自身にも見えません**。
- **当方（黒猫福家本舗）は、このデータを受け取りません。** データは利用者ご自身の Google ドライブの中にだけあります。
  当方はサーバーを持たないため、同期の内容を参照することはできません。
- **記事の本文と画像は同期しません**（各端末が自分で取り込みます）。同期されるのは一覧・状態・設定です。
- 同期は、利用者が <strong>設定 → つながり →「端末間の同期」</strong>で Google にサインインしたときだけ行われます（既定はオフ）。
  サインアウトすれば止まります。端末の購読・設定はそのまま残ります。
- サインインのとき、Google から**アカウントのメールアドレス**を受け取ります。どのアカウントで同期しているかを画面に表示するために
  **端末の中にだけ**保存し、当方には送りません。
- 「メインの端末」を決めるため、**本アプリが作るランダムな端末の ID と、端末の機種名**を、同期のデータと一緒に
  利用者ご自身の Google ドライブのアプリ専用フォルダに保存します（広告 ID ではありません）。

何がそろって何がそろわないか、数字がどう見えるかは、[端末間の同期のしくみ](/sync) をご覧ください。

### データの削除

| 権限 | 使いみち |

### フォアグラウンドサービスを使う理由（Even G2 連携）

Even G2 に記事を出しているあいだ、前面にいるのは Even Realities のアプリで、AURA は裏に回ります。
裏のままだと OS にプロセスを止められ、眼鏡からの読み出しに答えられなくなります。
そこで**連携を有効にしているあいだだけ**常駐通知付きのフォアグラウンドサービスを動かします。

- 動くのは、利用者が **設定 → つながり → Even G2（眼鏡）** を自分でオンにしたときだけです（既定はオフ）
- このサービスが開くのは **端末内だけに閉じた待ち受け（`127.0.0.1`）** で、端末の外からは接続できません
- 同じ端末の他のアプリから読まれないよう、**8 文字の合言葉**が合う要求にだけ応答します
- 記事の内容が端末の外へ送られることはありません
- オフにすれば、サービスも通知も止まります

### AURA for G2（Even G2 のプラグイン）

AURA for G2 は、Even Realities のアプリ（Even Hub）の中で動く、眼鏡に記事を出すためのプラグインです。
記事は、同じスマホの AURA から受け取ります。

| 項目 | 内容 |
| --- | --- |
| 求める権限 | **ネットワーク（network）だけ**。行き先は `http://127.0.0.1:8777`（同じスマホの AURA の待ち受け）に限っています |
| 通信する相手 | **同じスマホの AURA だけ**です。フォルダと記事の一覧・本文・画像を受け取り、既読と保存の切り替えを AURA に伝えます。AURA Plus かどうかの確認のため、5 秒ごとに AURA に問い合わせます |
| 端末の外への送信 | ありません。当方も記事や操作の記録を受け取りません |
| 保存するもの | 合言葉（8 文字）とポート、見え方の選択（未読・すべて・保存）。Even Realities のアプリの中の、このプラグイン用の保存場所に置きます |
| 使わないもの | マイク・カメラ・位置情報・写真は使いません |

- 眼鏡への表示は、Even Realities のアプリを通して行われます。その扱いは Even Realities のポリシーによります
- スマホ側の設定画面にある AURA Plus の案内のリンクは、押したときだけ当方のサイト（このサイト）をブラウザで開きます
