# プライバシーポリシー

最終更新: 2026-09-14 / 対象: AURA 1.0.0（Android）

AURA（以下「本アプリ」）は、**黒猫福家本舗**（以下「当方」）が提供する RSS リーダーです。
**当方は利用者の個人データを受け取りません**（当方はサーバーを運用していません）。
ただし、**無料版（Free）では記事の一覧に広告を表示するため、Google の広告 SDK（Google AdMob）を組み込んでいます**。
広告 SDK は、下記「2. 広告（無料版のみ）」の情報を **Google に**送ります。
**AURA Plus では広告を読み込まず、広告 SDK による通信も行いません。**
以下は、本アプリが実際に何をしているかの説明です。

## 1. 当方が収集する情報

**ありません。**

本アプリには利用者登録・ログインの仕組みがなく、当方はサーバーを運用していません。
アクセス解析・クラッシュレポートのための外部サービス（SDK）は組み込んでいません。
購読リスト・読んだ記事・既読と保存の状態・設定は、端末の外へ送りません（「4. 端末の中に保存するもの」）。
当方が、氏名・メールアドレス・端末の識別子・位置情報・利用状況などを受け取ることはありません。

## 2. 広告（無料版のみ）

無料版では、記事の一覧の **12 件ごとに 1 枠**、バナー広告を表示します。
**記事の本文・設定画面・Even G2（眼鏡）の表示・ウィジェットには広告を出しません。** 起動時の全画面広告もありません。
広告の配信には **Google AdMob**（Google LLC）を使います。

### 広告 SDK が Google に送る情報

広告を表示するとき、Google Mobile Ads SDK は次の情報を収集し、Google に送ります。

| 情報 | 内容 | 使いみち（Google による） |
| --- | --- | --- |
| 端末の識別子 | **広告 ID**（Android の Advertising ID）、**アプリセット ID** | 広告の配信、広告の効果測定、不正防止 |
| おおよその位置 | 通信の **IP アドレス**から推定される地域。**GPS などの正確な位置情報は使いません**（本アプリは位置情報の権限を持ちません） | 地域に合った広告、不正防止 |
| 広告の操作 | 広告の表示・タップ、アプリの起動などの操作 | 広告の配信と効果測定、不正防止 |
| 診断情報 | 広告 SDK のクラッシュログ、読み込みの速さなどの性能情報 | 広告 SDK の不具合の修正と性能の改善 |
| 端末とアプリの情報 | 端末の機種・OS の版・言語・画面の大きさ、本アプリの名前と版 | 端末に合った広告の表示 |

- **記事の内容・購読リスト・読んだ記事は、広告 SDK に渡しません。** 広告は記事の内容に合わせて選ばれるものではありません
- 通信は暗号化されています
- 情報の扱いは Google のポリシーによります。
  [Google のパートナーのサイトやアプリを使用する際の Google によるデータ使用](https://policies.google.com/technologies/partner-sites?hl=ja)・
  [Google のプライバシーポリシー](https://policies.google.com/privacy?hl=ja) をご覧ください

### 広告の設定と同意

- **広告 ID のリセット・削除**、パーソナライズド広告のオプトアウトは、端末の
  **設定 → Google → 広告**（端末により **設定 → セキュリティとプライバシー → その他のプライバシー設定 → 広告**）から行えます
- **EEA（欧州経済領域）・英国・スイスなど**、法令で同意が必要な地域では、広告を読み込む前に同意の画面を表示します
  （Google の User Messaging Platform）。同意の内容は、本アプリの **設定 → その他 →「広告の同意を変更する」** から変更できます
- **AURA Plus** にすると広告は表示されず、広告 SDK は広告を読み込みません

## 3. 端末の外への通信

本アプリが通信するのは、**利用者が読むために必要な相手**と、**無料版の広告の配信（Google）**です。いずれも当方のサーバーではありません。

| 通信先 | いつ | 何のため |
| --- | --- | --- |
| 利用者が登録した配信元（RSS / Atom の URL） | 取り込みのとき | 記事一覧の取得 |
| `news.google.com` | キーワード購読があるとき | 検索結果のフィード取得と、記事の実 URL の解決 |
| 記事の掲載サイト | 全文を取っておく設定のとき、記事を開くとき | 本文の取得 |
| 記事に含まれる画像の配信元 | 画像を表示・保存するとき | 画像の取得 |
| 配信元のサイトの `/favicon.ico` | 購読の追加時と更新時 | 一覧に出すアイコンの取得 |
| Google（AdMob・User Messaging Platform） | **無料版で**記事の一覧を表示するとき | 広告の取得と表示、同意の確認（「2. 広告」） |

- ファビコンは**配信元のサイトから直接**取得します。外部のファビコン取得サービスは使いません。
- これらの通信では、相手のサーバーに接続元の IP アドレスや User-Agent など、
  通常の HTTP 通信に伴う情報が渡ります。これは当方ではなく**各配信元**（広告は Google）が受け取るものです。
  取り扱いは各配信元のポリシーによります。
- 古い配信元のために、暗号化されていない通信（`http://`）も行えるようにしています。
  ただし **まず `https://` を試し、対応していない配信元の場合だけ** `http://` になります。
- 記事を外部のブラウザや「あとで読む」サービス（Pocket 等）で開くのは、利用者が操作したときだけです。
  以降の通信はそれらのアプリとサイトの間で行われます。

## 4. 端末の中に保存するもの

次のデータは、**すべて端末内のアプリ領域**に保存されます。当方へ送信されることはありません。

- 購読リスト、フォルダ、記事（タイトル・要約・本文）、既読と保存の状態（アプリ内のデータベース）
- 記事の画像のキャッシュ
- アプリの設定（テーマ、文字サイズ、更新間隔、Even G2 連携の合言葉など）
- 購読リストの自動バックアップ（月 1 回・6 世代まで）。保存先は
  アプリ専用の外部ディレクトリ（`Android/data/ca.kuroneko.aura/files/Documents/`）で、
  アプリを削除すると一緒に消えます
- アプリ内の動作ログ（設定 → Debug）。**端末のメモリ上に直近 500 件だけ**保持し、
  ファイルには書き出しません。アプリを終了すると消えます。利用者が「コピー」した場合のみ持ち出せます
- 無料版では、広告 SDK と同意の画面が、同意の状態や広告の表示に要る情報を端末内に保存します

アプリをアンインストールすると、これらは端末から削除されます。

:::info Android の自動バックアップについて
本アプリは Android の自動バックアップを有効にしています。端末の設定でバックアップが有効な場合、
購読リストや設定などのアプリデータが、**利用者自身の Google アカウント**のバックアップに含まれることがあります。
これは Android の機能であり、当方がその内容を参照することはできません。
:::

## 5. 第三者提供

当方はデータを保持していないため、**当方から第三者への提供・販売・共有はありません**。
無料版の広告 SDK が Google に送る情報は「2. 広告（無料版のみ）」のとおりです。

## 6. 権限について

| 権限 | 使いみち |
| --- | --- |
| インターネット / ネットワーク状態の取得 | 記事の取り込み。「Wi-Fi のときだけ更新する」の判定。無料版の広告の取得 |
| 通知の表示 | Even G2 連携を有効にしているあいだの常駐通知 |
| フォアグラウンドサービス（特殊用途 / `specialUse`） | 下記のとおり |
| 広告 ID（`AD_ID`）・Android の広告向けの機能（`ACCESS_ADSERVICES_*`） | 無料版の広告（広告 SDK が宣言するもの） |

### フォアグラウンドサービスを使う理由（Even G2 連携）

Even G2 に記事を出しているあいだ、前面にいるのは Even Realities のアプリで、AURA は裏に回ります。
裏のままだと OS にプロセスを止められ、眼鏡からの読み出しに答えられなくなります。
そこで**連携を有効にしているあいだだけ**常駐通知付きのフォアグラウンドサービスを動かします。

- 動くのは、利用者が **設定 → Even G2（眼鏡）** を自分でオンにしたときだけです（既定はオフ）
- このサービスが開くのは **端末内だけに閉じた待ち受け（`127.0.0.1`）** で、端末の外からは接続できません
- 同じ端末の他のアプリから読まれないよう、**8 文字の合言葉**が合う要求にだけ応答します
- 記事の内容が端末の外へ送られることはありません
- オフにすれば、サービスも通知も止まります

## 7. 子どもの利用について

本アプリは子ども向けに設計されたものではなく、13 歳未満の方を対象にしていません。
表示される記事の内容は、利用者が登録した配信元によります。
