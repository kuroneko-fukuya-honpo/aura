## 不具合を知らせるとき

次が分かると、こちらで再現しやすくなります。

1. 端末と Android のバージョン
2. AURA のバージョン（設定 → その他）
3. 何をしたときに、何が起きたか
4. 配信元の URL（特定の購読で起きる場合）

アプリの中に **Debug タブ**（設定 → Debug）があり、取り込みや全文取得の記録が残っています。
「すべてコピー」で貼り付けられます。**端末の外には自動で送られません**。
