# AURA — 使わせていただいたもの

最終更新: 2026-10-21 / 対象: **AURA**（Android）／提供元: **黒猫福家本舗**

AURA が使わせていただいている音・声・ライブラリのうち、クレジットの表示が条件になっているものを載せます。アプリの中でも、設定 →「情報とサポート」→「ライセンス」で同じものが読めます。

## 効果音

読み上げの始まりの音（ニュースの音・速報の音）に、OtoLogic の効果音を使っています。

- 効果音：OtoLogic（https://otologic.jp）CC BY 4.0
- 一部の音は、長さと音量を調整しています。
