# AURA — アカウントとデータの削除

最終更新: 2026-09-22 / 対象: **AURA**（Android）／提供元: **黒猫福家本舗**

:::info まず知っておいていただきたいこと
**AURA には、当方（黒猫福家本舗）が管理するアカウントはありません。** 利用者登録もログインもなく、
**当方はサーバーを運用していません。** そのため、当方の手元に削除すべき利用者のデータはありません。

AURA の「アカウント」は、**端末間の同期（AURA Plus）で利用者ご自身が使う Google アカウント**のことです。
同期のデータは、**利用者ご自身の Google ドライブの「アプリ専用フォルダ」**にだけ保存されます。
:::

## 1. 削除の手順（ご自身ですべて消せます）

### 手順 A — 同期のデータ（ご自身の Google ドライブ）を削除する

1. パソコンのブラウザで [Google ドライブ](https://drive.google.com/) を開きます
2. 右上の**歯車のアイコン → 「設定」**を開きます
3. 左の**「アプリの管理」**を開きます
4. 一覧から **AURA** を探し、右の**「オプション」→「ドライブから切断」**を選びます

切断すると、AURA がドライブのデータにアクセスする許可が取り消され、
**AURA のアプリ専用フォルダのデータは Google 側で削除されます**（Google ドライブの仕組みによるものです）。

> 同期を使っていない方（AURA Plus をお使いでない方、サインインしたことがない方）は、
> ドライブにデータがありません。この手順は不要です。

### 手順 B — 端末の中のデータを削除する

**AURA をアンインストールしてください。** 購読リスト・記事・既読と保存の状態・設定・画像のキャッシュ・
自動バックアップのファイルは、アンインストールで端末から削除されます。

消さずに止めるだけなら、アプリの **設定 → その他 →「端末間の同期」→「サインアウトする」**で
同期が止まります（端末の購読・設定はそのまま残ります）。

### 手順 C — 当方へ削除を申請する

上の手順をご自身で行えない場合や、削除の確認をご希望の場合は、メールでご連絡ください。

- **宛先**: [kuroneko.fukuya@gmail.com](mailto:kuroneko.fukuya@gmail.com)
- **件名**: `AURA アカウント削除申請`
- **本文に書いていただくもの**: **同期に使っている Google アカウントのメールアドレス**（それ以外は不要です）

**受付から 7 日以内**に、当方から返信します。
なお、**当方は利用者のデータを保持していないため、当方の側で削除できるデータはありません。**
返信では、上の手順 A・B のご案内と、当方に該当するデータが無いことの回答をいたします。

## 2. 削除されるもの／残るもの

| データ | どこにあるか | 削除の方法 | いつ消えるか |
| --- | --- | --- | --- |
| 購読リスト・フォルダ・記事・既読と保存の状態・設定・画像のキャッシュ・購読リストの自動バックアップ | **端末の中**だけ | 手順 B（アンインストール） | **即時**（アンインストールと同時） |
| 同期のデータ（購読・フォルダ・フィルタ・隠すルール・保存した記事・既読／未読・記事の一覧） | **利用者ご自身の Google ドライブのアプリ専用フォルダ** | 手順 A（ドライブから切断） | **Google の処理により削除されます** |
| 当方が保持する利用者のデータ | **ありません**（当方はサーバーを持ちません） | — | — |

### 残るもの

- **削除を申請されたメール本文**（手順 C をお使いの場合）。
  問い合わせ対応の記録として、当方のメールに**受領から 1 年間**保存し、その後削除します。
  このメールに含まれるのは、お送りいただいたメールアドレスと文面だけです
- **無料版の広告に関する情報**。無料版では Google AdMob が広告 ID などを Google に送ります
  （[プライバシーポリシー](/privacy)の「2. 広告」）。これは**当方ではなく Google が受け取る**もので、
  広告 ID のリセット・削除は端末の **設定 → Google → 広告**から行えます
- **Android の自動バックアップ**。端末の設定でバックアップが有効な場合、アプリのデータが
  **利用者ご自身の Google アカウント**のバックアップに含まれることがあります。
  削除は端末の **設定 → Google → バックアップ**から行えます（当方は参照できません）

## 3. 受付から削除完了までの目安

| | 目安 |
| --- | --- |
| 手順 A・B（ご自身で行う） | **その場で完了**します |
| 手順 C（メールでの申請） | **受付から 7 日以内**に返信します |
