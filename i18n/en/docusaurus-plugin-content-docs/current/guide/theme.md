# Theme and text

Go to **Settings > Appearance**.

## Theme

- **Match device** / **Light** (the default) / **Dark** / **Black** (pure black for OLED screens)

## Custom colors

Turn on **Use custom colors** to choose two colors. While it's off, AURA uses the default **ink and vermilion** colors.

- **Primary color** — The top bar, tabs, and drawer surfaces. Ink, Navy, Moss, Wine, Umber, Slate blue
- **Accent color** — Selection underlines, counts, and buttons. Vermilion, Indigo, Forest, Plum, Amber, Slate

The accent color also sets the color of the [Refresh progress](/guide/progress) bar.

## Text

- **Title** — Use a serif font for headlines, and set the **Title text size** (12–22 sp). This changes only the size of headlines in the list
- **Text size (overall)** — 80–160% (in 5% steps). As you move the slider, the sample below updates right away

You can also change the text size with **aA** at the top right of the article screen.
